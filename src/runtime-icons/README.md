# Runtime Icons

Product icons for each AI runtime Crew44 detects, shown in the onboarding scan list and elsewhere in the UI.

Sourced from [Lobe Icons](https://github.com/lobehub/lobe-icons) (MIT licensed). To refresh or add a new one, download the SVG from `https://raw.githubusercontent.com/lobehub/lobe-icons/master/packages/static-svg/icons/<slug>.svg` and save it here as `<provider>.svg` where `<provider>` matches the daemon's runtime provider ID (e.g. `claude`, `qwen`).

Icons that use `currentColor` (cursor, hermes, opencode, pi) inherit the parent element's text color; the rest ship with brand colors baked in.
